Arduino Based Automatic Fire Fighting Robot

About Project

This project uses Arduino Uno and flame sensors to detect fire. When fire is detected, the robot stops, the servo motor turns and the water pump is activated.

Components Used

  • Arduino Uno
  • Two Flame Sensors
  • Two TT DC Motors
  • L298N Motor Driver
  • Servo Motor
  • Mini Water Pump
  • Battery and Connecting Wires

Working Principle

  1. Flame sensors detect fire.
  2. Arduino receives sensor signals.
  3. Robot stops when fire is detected.
  4. Servo motor turns towards the target.
  5. Water pump activates.
